# 宣武医院网络自动认证系统 v2

自动完成宣武医院内网认证登录、心跳保活、断网检测、断线重连。

## 工作原理 - 三层检测架构

```
┌─────────────────────────────────────────────────────┐
│  第1层: Ping 检测 (每5秒)                            │
│  → Ping 认证服务器 192.168.64.21                     │
│  → 失败 = 完全断网，进入等待恢复模式                  │
│  → 成功 = 物理网络正常，进入第2层                     │
├─────────────────────────────────────────────────────┤
│  第2层: HTTP 认证检测 (每30秒)                       │
│  → 请求外网测试地址                                  │
│  → 被重定向 = 需要认证，自动登录                      │
│  → 正常响应 = 已认证，进入第3层                       │
├─────────────────────────────────────────────────────┤
│  第3层: 心跳保活 (每3分钟)                           │
│  → GET /out.htm 维持会话                             │
│  → 失败 = 可能掉线，立即触发第2层检测                 │
│  → 成功 = 继续保持                                    │
└─────────────────────────────────────────────────────┘
```

### 断网场景处理

| 场景 | 检测时间 | 处理方式 |
|------|----------|----------|
| 20分钟突然断网 | ≤5秒 | Ping失败 → 等待恢复 → 自动重连 |
| 2小时超时注销 | ≤30秒 | HTTP检测失败 → 自动重新登录 |
| 认证服务器重启 | ≤5秒 | Ping/HTTP失败 → 等待恢复 → 重连 |
| WiFi 断开重连 | ≤5秒 | Ping恢复 → 立即认证 |

## 使用方法

### 1. 配置

```bash
cp config.example.json config.json
```

编辑 `config.json`，填入你的用户名和密码。

### 2. 运行

```powershell
# 前台运行（可看日志，推荐调试时用）
.\auto_auth.ps1

# 只登录一次
.\auto_auth.ps1 -Once

# 后台静默运行
Start-Process powershell -ArgumentList "-WindowStyle Hidden -ExecutionPolicy Bypass -File .\auto_auth.ps1" -WindowStyle Hidden
```

### 3. 开机自启

```powershell
# 以管理员身份运行
.\auto_auth.ps1 -Install     # 安装开机自启
.\auto_auth.ps1 -Uninstall   # 卸载开机自启
```

## 配置说明

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `portal_url` | 认证服务器地址 | `http://192.168.64.21` |
| `username` | 用户名 | `9610340` |
| `password` | 密码 | 已配置 |
| `heartbeat_interval_sec` | 心跳间隔 | `180` (3分钟) |
| `check_interval_sec` | HTTP检测间隔 | `30` (30秒) |
| `test_url` | 外网测试地址 | 微软 captive portal |
